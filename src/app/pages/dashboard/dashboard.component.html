Threat Classifications & Severities

Threat Type Severity Detection Rules
Vulnerability Probe Critical Detects attempts to access sensitive files: .env, .git, /etc/ssl, /wp-admin, /actuator, webshell probes (shell.php), config backups (.sql, .key).
Path Traversal High Detects directory traversal patterns (../), SQL Injection (UNION SELECT, DROP TABLE), and XSS scripts.
Suspicious Scanner High Detects automated security scanning tools (sqlmap, nikto, nmap, masscan, gobuster, wpscan).
DDoS Burst Critical Triggers when an IP sends >= 5 requests within a 10-second window.
Bot Low Standard search engine crawlers and spiders (Googlebot, Bingbot, YandexBot).
