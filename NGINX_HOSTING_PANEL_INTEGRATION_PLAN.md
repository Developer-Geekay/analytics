# Architecture Plan: Core Hosting Panel Integration for Nginx Edge IP Restriction

## Executive Summary
This document specifies the architectural separation of responsibilities between the **Analytics App** (`analytics`) and the **Core Hosting Panel / Infrastructure Controller**.

The **Analytics App** operates as a microservice responsible for traffic analysis, threat detection, and providing REST APIs. System-level operations (modifying `/etc/nginx/conf.d/`, managing template files, and executing `sudo nginx -s reload`) are offloaded to the **Core Hosting Panel** via secure internal integration endpoints.

---

## 1. System Architecture & Boundaries

```
┌─────────────────────────────────────────┐         ┌─────────────────────────────────────────────┐
│              ANALYTICS APP              │         │             CORE HOSTING PANEL              │
│       (Client / Tenant Microservice)    │         │          (Infrastructure Controller)        │
├─────────────────────────────────────────┤         ├─────────────────────────────────────────────┤
│ • Ingests traffic & visit beacons       │         │ • Polls / Receives Webhooks for IP blocks   │
│ • Detects threats & signature forgery   │  HTTP   │ • Writes /etc/nginx/conf.d/global_blocked   │
│ • Manages BlockedIp MongoDB collection  │ ──────► │ • Writes /etc/nginx/conf.d/app_blocks/*.conf│
│ • Exposes Internal Export API Endpoint  │ JSON    │ • Deploys /etc/nginx/templates/custom_403   │
│ • Renders client-side JS overlay cards  │         │ • Executes `sudo nginx -t && nginx -s reload`│
└─────────────────────────────────────────┘         └─────────────────────────────────────────────┘
```

## 2. Analytics App Internal Export API Specification

The Analytics App exposes a lightweight internal API for the Core Hosting Panel:

### `GET /api/admin/security/export-nginx-blocks`
**Authorization**: `Bearer <ADMIN_TOKEN>` or `X-Internal-Secret: <INTERNAL_HOSTING_KEY>`

### B. Core Hosting Panel Sync Logic
1. **Poll / Webhook Trigger**: Every 1–5 minutes (or via Webhook event), the Core Hosting Panel calls `GET /api/admin/security/export-nginx-blocks`.
2. **Generate Global Block File**:
   Writes `/etc/nginx/conf.d/global_blocked_ips.conf`:
   ```nginx
   # Auto-generated by Core Hosting Panel
   deny 198.51.100.88;
   deny 198.51.100.99;
   ```
3. **Generate App-Scoped Block Files**:
   Writes `/etc/nginx/conf.d/app_blocks/app_<siteId>.conf`:
   ```nginx
   # Auto-generated by Core Hosting Panel for Site: 4d9f0164-38f3-4e0e-b55a-180132ebfb70
   deny 50.60.234.30;
   ```
4. **Nginx Reload**:
   Executes `sudo nginx -t && sudo nginx -s reload`.

## 4. Tenant Nginx Virtual Host Pattern

In each application's Nginx configuration managed by the Core Hosting Panel:

```nginx
server {
    listen 80;
    listen 443 ssl;
    server_name products.consoleapi.in;

    # 1. Custom Branded 403 Error Page for non-browser (cURL, Python, Postman) and browser clients
    error_page 403 /custom_403.html;
    location = /custom_403.html {
        root /etc/nginx/templates;
        internal;
    }

    # 2. Global IP Blocks
    include /etc/nginx/conf.d/global_blocked_ips.conf;

    # 3. App-Specific IP Blocks (Tenant: products)
    include /etc/nginx/conf.d/app_blocks/app_4d9f0164-38f3-4e0e-b55a-180132ebfb70.conf;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 5. Analytics App Internal Endpoint Implementation (`server.js`)

Add the internal export endpoint in `server.js` for the Core Hosting Panel:

```javascript
app.get('/api/admin/security/export-nginx-blocks', async (req, res) => {
  try {
    await connectToDatabase();
    const activeBlocks = await BlockedIp.find({ status: 'active' }).lean();

    const globalBlockedIps = [];
    const appScopedBlockedIps = {};

    activeBlocks.forEach(doc => {
      if (doc.scope === 'app' && doc.targetSiteId) {
        const siteKey = doc.targetSiteId.toLowerCase().trim();
        if (!appScopedBlockedIps[siteKey]) {
          appScopedBlockedIps[siteKey] = [];
        }
        appScopedBlockedIps[siteKey].push(doc.ip);
      } else {
        globalBlockedIps.push(doc.ip);
      }
    });

    return res.json({
      success: true,
      timestamp: new Date().toISOString(),
      data: {
        globalBlockedIps,
        appScopedBlockedIps
      }
    });
  } catch (err) {
    return res.status(500).json({ success: false, error: err.message });
  }
});
```

## Summary
- **Analytics App**: Owns threat detection, signature verification, `BlockedIp` database, internal export API, and client JS overlay rendering.
- **Core Hosting Panel**: Owns Nginx config files, template deployment, filesystem writing, and `nginx -s reload`.
